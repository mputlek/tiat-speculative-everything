# tiat-speculative-everything

Exhibition materials for a book club project built around Dunne & Raby's
*Speculative Everything*.

## Projects

- **[`globe-project/`](./globe-project)** — "Fun-Guy" mycelium healing
  globe: a multi-sensory installation visitors "talk to" via their phone,
  visualized as a living globe healing in real time. See its own README for
  setup and deploy instructions.

A related TouchDesigner + Ableton generative audio-visual piece
(movement-driven ambient soundscape) is a separate project, not tracked in
this repo.
